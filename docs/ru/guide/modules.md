# Встроенные модули

Полные имена встроенных модулей начинаются с `station.builtin`. Короткие имена ниже работают, пока другой доступный модуль не экспортирует то же имя. Параметры вложены в ключ модуля. Обязательные параметры отмечены словом **обязателен**.

Пакетные модули принимают только `present` и `absent` в `state`, без учёта регистра и окружающих пробелов. Явно переданные пустое значение и null недопустимы. Неверные параметры и ошибки запроса пакетов останавливают задачу до внесения изменений. Режим `check` сообщает те же ошибки, что и `apply`.

## `copy`

Копирует байты файла конфигурации в локальный файл. Перед записью сравнивает содержимое, создаёт родительские каталоги и может сохранить резервную копию. В режиме `check` сообщает только о необходимости записи.

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `file` | строка, **обязателен** | Логическое имя в `files/`. |
| `destination` | строка, **обязателен** | Путь назначения. |
| `backup` | логический, по умолчанию `true` | Сохранить старый файл как `.bak.<время UTC>`; при занятом имени добавить `.1`, `.2` и далее. |

```yaml
- copy:
    file: git/.gitignore_global
    destination: "{{ user_home }}/.gitignore_global"
```

## `template`

Вычисляет шаблон Scriban и записывает UTF-8 без BOM. Сравнивает полученные байты; назначение и резервное копирование работают так же, как у `copy`.

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `template` | строка, **обязателен** | Логическое имя в `templates/` без `.scriban` или `.sbn`. |
| `destination` | строка, **обязателен** | Путь назначения. |
| `backup` | логический, по умолчанию `true` | Сохранить старый файл перед изменением. |

```yaml
- template:
    template: git/config
    destination: "{{ user_home }}/.gitconfig"
```

Файлы роли имеют приоритет над корневыми файлами с таким же логическим именем. `copy` и `template` сообщают о необходимости прав администратора, если их требует путь назначения.

Оба модуля сначала полностью записывают временный файл рядом с фактическим назначением, затем заменяют существующий файл или публикуют новый. Для существующих файлов сохраняются правила доступа Windows или биты прав Unix; резервные копии получают те же права. Файл только для чтения вызывает ошибку без снятия его атрибутов. Каталог назначения должен разрешать создание, замену и удаление файлов.

Символические ссылки на файлы сохраняются: Station обновляет конечную цель, в том числе создаёт отсутствующую цель. Резервные копии остаются рядом с указанным в конфигурации путём назначения. Замена создаёт новый файловый объект, поэтому другие имена жёстких ссылок сохраняют старое содержимое.

Отмена до замены сохраняет существующее содержимое. При ошибке или отмене временные файлы и неиспользованные резервные копии удаляются, если права файловой системы позволяют это сделать. Успешное обновление сохраняет все прежние резервные копии; изменения в одну секунду получают отдельные имена с числовым суффиксом. Это свойства обновления отдельного файла. `apply` остаётся последовательным, без отката между задачами; принудительное завершение процесса может оставить временные файлы или файлы восстановления.

## `script`

Запускает скрипт из рабочего каталога задачи и ожидает один JSON-объект в стандартном выводе. По умолчанию запускается `pwsh`; Station передаёт `-NoLogo -NoProfile -File <путь-скрипта> <путь-запроса-json>`. Путь запроса также доступен через `CONFIG_TOOL_REQUEST_PATH`. Ненулевой код завершения или неверный JSON приводит к ошибке задачи. Поведение в режиме `check` реализует сам скрипт.

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `path` | строка, **обязателен** | Путь к скрипту внутри корня задачи. |
| `runner` | строка, по умолчанию `pwsh` | Исполняемый файл в `PATH`, принимающий указанные аргументы PowerShell. |
| `requiresAdmin` | логический, по умолчанию `false` | Запросить повышенные права при проверке. |

Входной JSON содержит `mode` (`check` или `apply`), `taskName`, `roleName` и `variables`. Выходной JSON может содержать `changed`, `failed`, `skipped`, `message` и `outputs`:

| Поле ответа | Допустимое значение | При отсутствии |
| --- | --- | --- |
| `changed`, `failed`, `skipped` | Логическое значение; строки, числа и null недопустимы. | `false` |
| `message` | Строка или null. | null |
| `outputs` | Объект или null. | null |

Ответ должен быть одним JSON-объектом с уникальными именами полей, включая вложенные объекты. Неверные типы приводят к ошибке задачи с диагностикой. Дополнительные поля игнорируются. Скрипт может вернуть одновременно `changed: true` и `failed: true`, если успел внести часть изменений до ошибки.

```powershell
$request = Get-Content -LiteralPath $args[0] -Raw | ConvertFrom-Json
$wouldChange = $true
@{
    changed = $wouldChange
    failed = $false
    message = if ($request.mode -eq 'check') { 'Изменится' } else { 'Изменено' }
} | ConvertTo-Json -Compress
```

Это только пример протокола. Настоящий скрипт должен проверять состояние и изменять его только при `mode = apply`.

## `winget`

Управляет пакетом через Windows Package Manager. При проверке команда должна быть доступна в `PATH`. Область `machine` требует повышенных прав.

Station запрашивает точный установленный ID и сравнивает с `version` колонку установленной версии. Код WinGet «приложения не найдены» отличается от ошибок запроса. Нераспознанный, усечённый или неоднозначный табличный ответ приводит к ошибке задачи. См. [контракт WinGet list](https://learn.microsoft.com/windows/package-manager/winget/list).

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `id` | строка, **обязателен** | Точный идентификатор пакета. |
| `state` | строка, по умолчанию `present` | `present` устанавливает, `absent` удаляет. |
| `version` | строка, необязателен | Версия для установки. |
| `scope` | строка, необязателен | `user` или `machine`; применяется к запросам, установке и удалению. `machine` требует повышенных прав. |
| `command` | строка, по умолчанию `winget` | Имя или путь исполняемого файла. |

```yaml
- winget:
    id: Git.Git
    state: present
```

## `scoop`

Управляет пакетом Scoop. При проверке команда должна быть в `PATH`. Глобальная установка требует повышенных прав.

Установленные пакеты читаются через [`scoop export`](https://github.com/ScoopInstaller/Scoop/blob/master/libexec/scoop-export.ps1). Station сопоставляет точное имя приложения в выбранной локальной или глобальной области. Похожее имя или установка в другой области не удовлетворяют задаче. Неверный ответ инвентаризации и незавершённая установка приводят к ошибке.

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `name` | строка, **обязателен** | Имя пакета или `bucket/name`. Bucket выбирает источник установки; проверка установленного пакета и удаление используют имя приложения. |
| `state` | строка, по умолчанию `present` | `present` устанавливает, `absent` удаляет. |
| `global` | логический, по умолчанию `false` | Передавать `--global` при установке и удалении. |
| `command` | строка, по умолчанию `scoop` | Имя или путь исполняемого файла. |

```yaml
- scoop:
    name: ripgrep
    state: present
```

## `apt`

Управляет пакетом через `apt-get` в Linux или в указанном дистрибутиве WSL на Windows. Проверяет наличие `apt-get` локально либо `wsl` и дистрибутива на Windows.

Station читает состояние и версию через [`dpkg-query`](https://manpages.debian.org/trixie/dpkg/dpkg-query.1.en.html). Оставшиеся конфигурационные файлы считаются отсутствующим пакетом. Частично установленный пакет требует установки для `present` или удаления для `absent`. Фатальная ошибка запроса и неверный формат состояния останавливают задачу. На Windows используется прямой запуск команды через WSL, список дистрибутивов читается как UTF-16.

| Параметр | Тип | Назначение |
| --- | --- | --- |
| `name` | строка, **обязателен** | Точное имя Debian-пакета, при необходимости в форме `name:architecture`. Шаблоны поиска недопустимы. |
| `state` | строка, по умолчанию `present` | `present` устанавливает, `absent` удаляет. |
| `version` | строка, необязателен | Нужная версия пакета. |
| `distribution` | строка | На Windows обязателен; имя дистрибутива WSL. |
| `sudo` | логический, по умолчанию `true` | Добавлять `sudo` перед изменяющей пакет командой. |
| `wslCommand` | строка, по умолчанию `wsl` | Исполняемый файл WSL. |
| `aptGetCommand` | строка, по умолчанию `apt-get` | Исполняемый файл пакетного менеджера. |

```yaml
- apt:
    name: ripgrep
    state: present
    distribution: Ubuntu
```

В примере `distribution` нужен на Windows. При запуске непосредственно в Linux его можно опустить.
