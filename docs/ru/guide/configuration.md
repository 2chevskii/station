# Корень конфигурации

Station читает один каталог как корень конфигурации. Обязательный `station.yaml` представляет внутреннюю модель конфигурации в формате YAML.

```text
workstation/
├── station.yaml
├── vars/
│   ├── 00-common.yaml
│   └── 10-machine.js
├── files/
├── templates/
├── roles/
│   └── git/
│       ├── defaults.yaml
│       ├── role.yaml
│       ├── files/
│       └── templates/
├── modules/
│   └── MyModule/
│       └── MyModule.dll
└── plugins/
```

В корне обязателен `station.yaml`. Его список `roles` должен содержать хотя бы одно имя роли, а у каждой выбранной роли должно быть определение. Остальные корневые поля необязательны.

## `station.yaml`

```yaml
roles:
  - git
  - team.workstation

plugins:
  - provider: local
    name: team-plugin

vars:
  user_name: Example User
  git:
    default_branch: main

tasks:
  - name: Установить Git
    winget:
      id: Git.Git
      state: present
```

| Поле | Тип | Назначение |
| --- | --- | --- |
| `roles` | Непустой список строк | Роли в порядке выполнения. Допустимы полные имена и однозначные короткие имена. |
| `plugins` | Список строк или объектов | Источники плагинов; см. [Плагины](./plugins.md). |
| `vars` | Объект | Корневые переопределения переменных. |
| `tasks` | Список объектов задач | Задачи, выполняемые перед выбранными ролями. |

Каталоги `roles/`, `modules/` и `plugins/` предоставляют локальные компоненты; перечисление роли в поле `roles` файла `station.yaml` выбирает её для выполнения. Полное имя роли или модуля включает поставщика: локальные компоненты имеют префикс `station.local`, встроенные модули — `station.builtin`, плагины — `name` из манифеста. Короткое имя допустимо, если оно однозначно в своём пространстве имён ролей или модулей.

## Файлы и шаблоны

`files/` содержит исходные файлы для `copy`. `templates/` содержит шаблоны Scriban для `template`. У роли могут быть собственные `files/` и `templates/`; при одинаковом логическом имени файл роли имеет приоритет над корневым. Имя шаблона указывается без расширения `.scriban` или `.sbn`.

Например, `template: git/config` может разрешиться в `templates/git/config.scriban`. Подробнее о подстановке: [Переменные и шаблоны](./variables.md).

## Форматы файлов

Корневой манифест — `station.yaml`. Файлы в `vars/` могут иметь расширение `.yaml` или `.js`. Роль использует либо `role.yaml`, либо `role.js` и при необходимости либо `defaults.yaml`, либо `defaults.js`. Station отклоняет два формата одного артефакта роли и корневые файлы переменных с одинаковым базовым именем. См. [Роли и задачи](./roles-and-tasks.md) и [Роли на JavaScript](./javascript-roles.md).
